PADRÕES DE INTERACÇÃO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

FEEDBACK VISUAL IMEDIATO
  Todo o botão ou card tocável deve ter feedback visual em <100ms.
  Em React Native: usar TouchableOpacity com activeOpacity=0.8
  ou Pressable com scale animation 0.97 no press.

ESTADOS DE LOADING
  Nunca mostrar um ecrã vazio sem indicação de carregamento.
  Usar skeleton screens (rectangulos cinzentos animados) em vez
  de spinner central quando há lista de cards a carregar.
  ActivityIndicator só para acções pontuais (enviar pedido, confirmar).

TOASTS VS ALERTS
  Toast (fundo navy, no fundo do ecrã): para feedback de acções
  que não requerem resposta do utilizador.
  Bottom Sheet: para confirmações que requerem decisão.
  Nunca usar Alert.alert() nativo — quebra o design.

ANIMAÇÕES
  Duração: 200-300ms para micro-interacções, 300ms para modais/sheets.
  Easing: ease para entrada, ease-in para saída.
  Reanimated: usar para animações de performance crítica
  (ex: approach bar, marcadores no mapa, toggle switch).

HIERARQUIA DE TIPOGRAFIA
  Título de ecrã      : Sora 22px bold, cor navy
  Título de secção    : Sora 16-17px bold, cor navy
  Nome de pessoa/lugar: DM Sans 15-16px semi-bold, cor navy
  Metadados/subtítulo : DM Sans 12-13px regular, cor text2 (#4B5775)
  Etiquetas/pills     : DM Sans 11px semi-bold
  Labels tiny         : DM Sans 10px bold uppercase, letter-spacing 0.07em
